# weather-app
A simple weather forecasting app that allows users to enter a city name and view the current weather conditions (temperature, humidity, wind speed, etc.) using the OpenWeatherMap API.


## Features
- Displays weather data such as temperature, condition, humidity, and wind speed.
- Fetches weather data using the OpenWeatherMap API.
- Ability to switch between dark and light themes.
- Error handling for invalid city names and failed API requests.
- Auto-detects the user's location using geolocation for weather updates.

## Tech Stack
- **HTML**: Structure of the weather app.
- **CSS**: Styles for the light/dark themes and layout.
- **JavaScript**: Handles API requests, geolocation, and DOM manipulation.
- **OpenWeatherMap API**: Provides weather data.
